## 🧭 What I Do

- **Enterprise Backend & Modernization** — Java/Spring 기반 레거시 분석, 성능 개선, 클라우드·플랫폼 이관

- **Technical Leadership** — 고객 협의, 파트 리딩, 팀원 교육, AI 파일럿에서 조직 확산까지 실행
